# Gold Pulse

Gold Pulse คือเว็บสรุปข่าวและเหตุการณ์ที่อาจส่งผลต่อทองคำและ XAUUSD แบบอ่านง่ายสำหรับคนเริ่มต้น

## เวอร์ชันนี้ทำอะไรได้บ้าง

- สรุปภาพรวมแรงหนุน/แรงกดดันทอง
- แสดงเหตุการณ์สำคัญพร้อมเวลาไทย
- กรองเหตุการณ์เป็นหนุนทอง, กดดันทอง และผันผวน
- กดเปิดเหตุผลและลิงก์แหล่งข้อมูลต้นทาง
- อธิบายความสัมพันธ์ของดอลลาร์, บอนด์ยีลด์, ดอกเบี้ย และทอง
- แสดงเหตุผลของมุมมองพร้อมแหล่งอ้างอิงหลัก
- ใช้งานบนมือถือ
- เตรียม GitHub Actions สำหรับ GitHub Pages

> ข้อมูลราคาและเหตุการณ์ใน MVP นี้เป็นข้อมูลตัวอย่างเพื่อทดสอบหน้าตาและการใช้งาน ยังไม่ใช่ข้อมูลสดหรือคำแนะนำการลงทุน

MVP นี้ตั้งใจเริ่มจากแหล่งข้อมูลทางการและแหล่งวิเคราะห์ที่มีบทความต้นฉบับก่อน ยังไม่รวมกระแสจากโซเชียล เพื่อไม่ให้สัญญาณรบกวนปนกับข้อมูลหลัก

## แผนต่อยอดแบบไม่เสียเงิน

1. ดึงตารางประกาศจากหน่วยงานทางการ เช่น Fed, BLS, BEA และ FRED
2. เพิ่มตัวอัปเดตข้อมูลด้วย GitHub Actions ตามรอบเวลา
3. เพิ่มราคาทองแบบหน่วงหรือ indicative จากแหล่งที่อนุญาต
4. เพิ่มประวัติว่าเหตุการณ์แต่ละประเภทเคยทำให้ทองตอบสนองอย่างไร

## หมายเหตุ

เว็บนี้เป็นเครื่องมือเพื่อการศึกษา ไม่ใช่ระบบให้สัญญาณซื้อขาย และไม่ควรใช้ข้อมูลเพียงหน้าเดียวในการตัดสินใจลงทุน
