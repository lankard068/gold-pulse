# Gold Pulse

Gold Pulse คือเว็บสรุปข่าวและเหตุการณ์ที่อาจส่งผลต่อทองคำและ XAUUSD แบบอ่านง่ายสำหรับคนเริ่มต้น

## เวอร์ชันใช้งานจริงทำอะไรได้บ้าง

- ดึงราคาทอง XAU spot จาก XAUS พร้อมเวลาและแหล่งที่มา
- ดึงดอลลาร์ Broad และ US 10Y จาก FRED
- ดึงข่าวจริงจาก Federal Reserve, BLS, FXStreet, MarketWatch และ The Guardian เท่าที่ฟีดตอบกลับ
- คัดเฉพาะข่าวที่เกี่ยวกับทอง ดอลลาร์ ยีลด์ Fed เงินเฟ้อ และความเสี่ยงตลาด
- สรุปภาพรวมแรงหนุน/แรงกดดันทองจากข้อมูลจริงแบบ rule-based
- แสดงข่าว/เหตุการณ์จริงพร้อมเวลาไทย ลิงก์ต้นฉบับ และภาพจาก RSS ถ้ามี
- แสดงกราฟแท่งเทียน XAUUSD จาก TradingView
- กรองเหตุการณ์เป็นหนุนทอง, กดดันทอง และผันผวน
- กดเปิดเหตุผลและลิงก์แหล่งข้อมูลต้นทาง
- แสดงภาพ Preview จาก RSS เมื่อแหล่งข่าวอนุญาต ถ้าไม่มีจะใช้ภาพประกอบที่ติดป้ายชัดเจน
- อธิบายความสัมพันธ์ของดอลลาร์, บอนด์ยีลด์, ดอกเบี้ย และทอง
- แสดงเหตุผลของมุมมองพร้อมแหล่งอ้างอิงหลัก
- ใช้งานบนมือถือ
- GitHub Actions อัปเดต snapshot อัตโนมัติทุก 30 นาที

> ระบบใช้ข้อมูลสดจากผู้ให้บริการภายนอกและอาจมีความหน่วง/หยุดชั่วคราวได้ จึงแสดงเวลาอัปเดตและต้นทางทุกครั้ง

MVP นี้ตั้งใจเริ่มจากแหล่งข้อมูลทางการและแหล่งวิเคราะห์ที่มีบทความต้นฉบับก่อน ยังไม่รวมกระแสจากโซเชียล เพื่อไม่ให้สัญญาณรบกวนปนกับข้อมูลหลัก

## โครงสร้างข้อมูล

- `scripts/update-data.mjs` ดึงและรวมข้อมูลภายนอก
- `data/live.json` snapshot ล่าสุดที่หน้าเว็บอ่านไปแสดงผล
- `.github/workflows/update-data.yml` ตั้งเวลาอัปเดตทุก 30 นาที

หมายเหตุ: ฟีด BLS อาจปฏิเสธคำขออัตโนมัติบางช่วง ระบบจะเก็บข้อมูลล่าสุดที่สำเร็จไว้แทน ไม่ลบข้อมูลเดิมทิ้ง

## หมายเหตุ

เว็บนี้เป็นเครื่องมือเพื่อการศึกษา ไม่ใช่ระบบให้สัญญาณซื้อขาย และไม่ควรใช้ข้อมูลเพียงหน้าเดียวในการตัดสินใจลงทุน
